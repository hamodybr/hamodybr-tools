# HAMODYBR Tools

Fast, free and privacy-first everyday browser tools.

## Current release: V2.5

### Images
- Compress Image
- Resize Image
- Convert JPG / PNG / WebP
- Image to PDF
- Batch Compress Images
- Batch Resize Images
- Remove Image Metadata

### PDF
- Merge PDF
- Split / Extract PDF Pages
- Organize PDF — reorder and rotate pages

### Text & Utilities
- QR Code Generator
- Password Generator
- Word & Character Counter
- Text Cleaner
- JSON Formatter
- Case Converter
- URL Encoder / Decoder
- Color Converter

## Principles
- Mobile-first
- No signup
- Browser-side processing whenever possible
- Lightweight static deployment
- PWA-ready

Social-media downloading is intentionally postponed while the core utility suite is expanded.
