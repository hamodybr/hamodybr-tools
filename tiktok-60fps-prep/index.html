The first run downloads a pinned single-thread FFmpeg WebAssembly engine. Your selected video itself is not uploaded to HAMODYBR or to the FFmpeg CDN. Large files need enough free memory on the iPhone.

Test workflow

  1. Select the untouched 60 FPS original.
  2. Tap Prepare video and wait until the file is ready.
  3. Save/share the prepared MP4 to the iPhone.
  4. Confirm it shows approximately 30 FPS and roughly 2× duration.
  5. Import it into TikTok and test the same 2× speed workflow.
  6. After posting, inspect the downloaded TikTok result so we can verify the final FPS.
