Reference mode intentionally creates non-standard timing relationships for testing. Player behavior can differ. This does not guarantee TikTok distribution or For You eligibility; content-policy decisions are separate from encoding quality.

Test plan

  1. Use one original 60 FPS clip, ideally 5–15 seconds with camera/object motion and fine detail.
  2. Generate Reference 120→60 Patch first.
  3. Generate Control 1080p60 from the exact same source.
  4. Inspect both in MediaInfo. For Reference, look for ~60 FPS plus evidence of 120 FPS/original timing, normal duration, H.264 High, 1080×1920, GOP 30 and high bitrate.
  5. Upload both privately using the same TikTok workflow, then compare the published/downloaded files — not only the preview.
